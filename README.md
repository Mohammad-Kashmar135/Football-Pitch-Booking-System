## 📖 About The Project

A comprehensive full-stack application for booking football pitches. This project aims to provide a seamless and professional platform for managing pitch reservations. The system is powered by a robust and reliable API built with the **NestJS** framework, supported by strict Data Transfer Object (DTO) validation. The application also features a modern, responsive frontend to ensure an optimal user experience across all devices.

## 🛠️ Technologies Used

* **Backend:** NestJS, TypeScript, Class-Validator (Robust DTO Validation).

* **Frontend:** Responsive Web Interface.

* **Environment:** Node.js, npm.

## 🚀 Getting Started

To run the project locally, you will need to start both the backend (API) and the frontend (Client) in two separate terminal windows.

### 1. Running the Backend (API)

Navigate to the `api` directory, install the dependencies (if you haven't already), and start the production server:

```
cd api
npm install
npm run start:prod

```

*(Note: the command is `start:prod` to match standard NestJS production scripts).*

### 2. Running the Frontend (Client)

Open a new terminal window, navigate to the `client` directory, install the dependencies, and start the development server:

```
cd client
npm install
npm run dev

```

## 📌 Features

* **Robust Data Validation:** Utilizes DTOs to ensure the security and integrity of inputs before processing.

* **Responsive Design:** A user interface that works flawlessly on all screen sizes (mobile phones, tablets, desktops).
